# FitLog

FitLog is a workout tracking web application where users can browse exercises, view detailed workout information, save workouts for later, and create a daily workout plan.

## Technologies Used

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Toastify


## Key Features

1. Browse a workout library with exercise details.
2. View detailed workout information including equipment, difficulty, sets, reps, calories, and rating.
3. Add up to five workouts to today's plan.
4. Save workouts for later and manage saved workouts.
5. Mark planned workouts as completed or remove them from the plan.
